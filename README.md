# Dota Analytics

Веб-приложение для чтения публичной статистики Dota 2: профиль игрока, матчи, герои, дуэт и сравнение двух профилей.

Цифры берутся из [OpenDota](https://www.opendota.com/). Вход через Steam нужен только для своего профиля. Чужие публичные профили открываются без аккаунта.

## Что можно сделать

- Найти игрока по нику, номеру аккаунта или ссылке `steamcommunity.com`.
- Открыть профиль: винрейт, недавние матчи, активность, частые герои, ранг.
- Посмотреть матч, героя и текущий срез героев.
- Сравнить два профиля рядом.
- Посмотреть дуэт: игры вместе и друг против друга. Это не то же самое, что сравнение, и общие матчи не означают, что игроки были в пати.

Friend Code (`s.team/p/...` и код вида `XXXX-XXXX`) профилем не является.

## Запуск

Нужны Node.js 18.18 или новее и npm.

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

Сборка и запуск production-сборки:

```bash
npm run build
npm start
```

## Переменные окружения

Создайте `.env.local` в корне. Файл не коммитится. Все ключи необязательны: без них читаются публичные профили по номеру аккаунта и по ссылке вида `/profiles/7656...`.

```bash
# Необязательно. Повышает лимит запросов OpenDota.
OPENDOTA_API_KEY=

# Нужен, чтобы открывать короткие адреса Steam: steamcommunity.com/id/ник
STEAM_WEB_API_KEY=

# Секрет подписи сессии после входа через Steam. Минимум 16 символов.
# Без него сессия живёт только до перезапуска процесса.
SESSION_SECRET=
```

Ключ Steam выдаётся на [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey). Секрет сессии можно сгенерировать локально:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Ключи остаются на сервере и не попадают в браузер.

## Откуда данные

| Что | Источник |
| --- | --- |
| Матчи, герои, винрейт, ранг | OpenDota |
| Короткий адрес Steam (`/id/ник`) | Steam Web API |
| Вход «это мой профиль» | Steam OpenID |
| Медали ранга | Картинки из клиента Dota 2, лежат в `public/ranks` |

OpenDota отвечает не мгновенно: на время запроса показывается знак загрузки. Часть истории может отсутствовать, если матчи не публичные или ещё не разобраны. Приложение не подменяет отсутствующие цифры и не усредняет разные источники.
